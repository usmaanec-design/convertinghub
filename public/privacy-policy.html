ConvertingHub Privacy Policy

Last Updated: August 23, 2026
Privacy Summary: ConvertingHub is built with a privacy-first architecture. Most file conversions occur directly inside your browser/device client-side. When complex document conversion requires server processing, your files are transmitted via secure TLS encryption, processed ephemerally in memory, and immediately deleted without permanent storage or tracking.

1. Information We Process

ConvertingHub provides multi-format file conversion utilities across document, image, audio, video, and archive formats. Data processing occurs in two ways depending on the target format:

  • Client-Side Processing (Local): Image optimizations, webp conversions, client-side PDF parsing, and utility tools run entirely inside your browser or device memory. Your files never leave your device.
  • Server-Side Ephemeral Processing: Complex document conversions (e.g., LibreOffice office conversions) transmit your file securely over HTTPS/TLS to our conversion API server (`convertinghub-backend.onrender.com`). Files are held in temporary memory solely for the duration of the conversion execution and are automatically discarded immediately upon completion.

2. Data Collection & Usage

We do not collect personal identification details, sell user data to third parties, or build behavioral user profiles. The data processed during file conversion is used strictly to fulfill your requested file transformation service.

3. Data Security & Encryption

All network transmissions between the ConvertingHub client application (Web, Android, and Windows desktop) and backend servers are encrypted using standard TLS 1.3 (HTTPS) encryption to prevent unauthorized interception.

4. No Permanent File Storage

ConvertingHub does not store your original files or converted output files on persistent server storage. All file buffers are cleared automatically after processing.

5. Third-Party Infrastructure

Our web platform and backend infrastructure utilize trusted cloud providers, including Firebase Hosting (Google Cloud) and Render. These infrastructure providers adhere to industry-standard data security and privacy compliance framework.

6. Contact Us

If you have questions regarding this Privacy Policy or data privacy compliance, please reach out through our official platform at https://convertinghub-official.web.app.
